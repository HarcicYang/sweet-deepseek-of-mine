# 临时对话分享

分享链接保存的是创建时的只读对话快照，不是实时会话，也不会随后续编辑自动更新。

## 行为

- 默认有效期 3 天，创建者可设置 1–30 天。
- 快照只包含当前选中的消息分支，不暴露其他版本。
- 附件只保留文件名、大小、类型等元数据；不复制附件原件，也不保留可用于再次访问文件的
  `serverId`。
- MCP 工具调用参数和工具输出不进入公开快照；只保留工具调用步骤名称，避免把账号内部的
  查询参数或返回数据暴露给访客。
- 分享页不加载 API Key、本地聊天数据库或附件原件，不提供发送、编辑、重新生成和版本切换。
- 复制和朗读等只读操作可以继续使用。
- 链接 token 使用高熵随机值；过期后公开接口返回不存在。

## API

- `POST /api/shares`：要求登录，提交会话快照和 `expiresInDays`，返回临时链接。
- `GET /api/shares/:token`：公开只读接口，不要求登录；允许任意前端 origin 读取，响应不缓存。

## 存储

- Node adapter 使用独立 JSON 文件，可由 `SHARE_DB_PATH` 配置。
- Workers adapter 使用 D1 的 `share_links` 和 `share_chunks`；快照按 512 KiB 分块，
  避免受 D1 单行大小限制。
- 创建新分享时机会式清理已过期记录。
